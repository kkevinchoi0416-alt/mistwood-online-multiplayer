MISTWOOD ONLINE MULTIPLAYER
===========================

이 폴더는 기존 MISTWOOD MOTORSPORT와 별개인 새 온라인 게임입니다.
기존 게임 파일은 변경하지 않습니다.

포함된 차량
-----------
기존 차량 시스템에서 가져온 21종 차량을 사용할 수 있습니다.
일반 차량, VIP 차량, 관리자 전용 차량, 차량별 최고속도·가속·조향·특성 정보가 포함됩니다.

VIP 전용 차량은 VIP 인증 후, 관리자 차량은 관리자 인증 후 선택할 수 있습니다.
기본 PIN은 VIP=sindorim!, 관리자=0011 입니다.
이 PIN은 서버에서 확인하며 index.html에 비밀번호를 넣어 두지 않았습니다.
실제 공개 서버를 운영할 때는 호스팅 서비스의 환경 변수에서 VIP_PIN과 ADMIN_PIN을 바꾸는 것을 권장합니다.

게임 방식
---------
1. 게임에 접속해 닉네임과 PC/모바일 조작을 선택합니다.
2. 차량을 고릅니다.
3. '새 온라인 방 만들기'를 눌러 방 코드를 만듭니다.
4. 친구에게 방 코드를 알려 줍니다.
5. 친구는 같은 사이트에서 방 코드를 입력하고 '방 참가'를 누릅니다.
6. 방장이 '드라이브 시작'을 누르면 최대 8명이 같은 숲속 서킷에서 함께 운전합니다.

조작
----
PC: W/A/S/D 또는 방향키, Space 브레이크, F 차량 부스트(사용 가능한 차량만)
모바일: 화면의 방향키, BRAKE, BOOST 버튼

내 컴퓨터에서 테스트하기
-----------------------
1. Node.js LTS(버전 18 이상)를 설치합니다: https://nodejs.org
2. 이 폴더에서 start_windows.bat을 더블클릭합니다.
3. 검은색 창에 `MISTWOOD Online server listening on port 3000`이 표시되면 서버가 켜진 것입니다. 별도의 npm 패키지 설치는 필요하지 않습니다.
4. 브라우저에서 http://localhost:3000 을 엽니다.
5. 친구가 같은 Wi-Fi에 있으면 내 컴퓨터의 내부 IP 주소와 :3000 포트로 접속할 수 있습니다.
   서로 다른 장소의 친구는 아래와 같이 온라인 호스팅을 해야 합니다.

친구들과 인터넷으로 플레이하기
------------------------------
중요: GitHub Pages는 HTML 파일을 보여 주는 정적 호스팅이라 실시간 WebSocket 서버를 실행할 수 없습니다.
따라서 이 프로젝트 폴더 전체를 Node.js 서버를 실행할 수 있는 호스팅(Render 등)에 배포해야 합니다.

Render 예시:
1. 이 폴더 전체를 새 GitHub 저장소에 올립니다. index.html만 올리면 안 됩니다.
2. Render에서 New > Web Service를 만들고 그 저장소를 연결합니다.
3. Build Command: npm install
4. Start Command: npm start
5. 배포가 끝나면 Render가 주는 https://... 주소로 접속합니다.
6. 친구에게 그 주소와 방 코드를 보내면 됩니다.

이 서버는 같은 주소에서 웹페이지와 WebSocket 연결을 함께 제공합니다.
HTTPS 사이트에서는 브라우저가 자동으로 WSS 보안 연결을 사용합니다.
무료 호스팅은 사용하지 않을 때 잠들 수 있어 첫 접속이나 방 생성이 늦어질 수 있습니다.

관리자 및 VIP 비밀번호
----------------------
기본값은 이전 게임에서 쓰던 값을 사용합니다.
공개 서버에서는 Render의 Environment에 다음 변수를 설정하면 기본값 대신 바뀐 비밀번호를 사용합니다.
ADMIN_PIN=새 관리자 비밀번호
VIP_PIN=새 VIP 비밀번호

참고 및 제한
------------
- 이 게임은 기존 게임과 분리된 별도 프로젝트입니다.
- 실시간 위치와 차량 상태는 온라인 서버를 통해 공유됩니다.
- 현재 최대 인원은 방 하나당 8명입니다.
- 게임 그래픽은 Three.js를 CDN에서 내려받으므로 인터넷 연결이 필요합니다.
- 게임 페이지 스크립트는 top-level await를 지원하도록 JavaScript 모듈 방식으로 실행됩니다.
- 네트워크 지연, 학교/기관 Wi-Fi의 WebSocket 차단, 호스팅 서버의 절전 상태에 따라 접속이 달라질 수 있습니다.
- 인증 PIN은 서버에서 검사하지만 기본 PIN을 공개한 채로 운영하지 말고, 공개 배포 전 환경 변수에서 변경하는 것이 좋습니다.

Render 배포 중 환경 변수 입력 화면이 나오면 다음 값을 넣어 주세요.
ADMIN_PIN: 기존 관리자 PIN 또는 원하는 새 PIN
VIP_PIN: 기존 VIP PIN 또는 원하는 새 PIN
서버 코드에는 환경 변수가 우선 적용되고, 미설정 시 이전 게임의 기본 PIN이 사용됩니다.
GitHub 저장소가 공개 상태라면 소스 코드에 기본값이 보일 수 있으므로, 공유 전에 Render 환경 변수에서 새 값으로 바꾸는 것을 권장합니다.
