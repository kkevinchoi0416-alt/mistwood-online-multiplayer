# MISTWOOD ONLINE V2 — 멀티플레이 레이싱 업데이트

## 최신 레이스 UI 업데이트
- 첫 번째 완주자가 나온 뒤 20초 종료 카운트다운을 모든 참가자 화면 상단에 표시합니다. 서버의 종료 시각을 기준으로 계산하므로 참가자마다 시간이 따로 흐르지 않습니다.
- 내 화면에서는 내 차량 이름표를 숨기고, 다른 참가자의 화면에는 내 이름표가 보입니다.
- 게임 화면 상단에 PC 키보드 또는 모바일 조작 안내가 표시됩니다.
- 부스트 사용 가능 횟수(5회 중 남은 횟수), 3초 작동 시간, 10초 재장전 시간을 HUD에 표시합니다.
- 시작 화면을 모터스포츠 스타일의 대시보드형 UI로 새롭게 정리했습니다.


## 포함 파일
- `index.html`: 레이싱 홈 화면, 게임 HUD, 종료 카운트다운, 이름표 표시, 조작 안내, 부스트 재장전 표시, 차량 선택, 튜닝 슬라이더, 10개 맵 선택
- `server.js`: 온라인 방, 서버 권한 주행 물리, 랩 계산, 부스트 제한
- `vehicles.json`: 차량 외형/선택 데이터
- `tracks.json`: 10개 맵의 웨이포인트와 설명
- `package.json`: Node.js 실행 명령
- `render.yaml`: Render 배포 설정

## 실행
- Render Web Service의 Build Command: `npm install`
- Start Command: `npm start`
- Root Directory: 비워 둡니다.
- Runtime: Node

## 튜닝 코드 위치
`index.html`의 `TUNE_FIELDS`가 슬라이더 범위·간격·설명을 정합니다. `renderTuneFields()`가 UI를 만들고, 서버 `sanitizeTune()`이 범위를 한 번 더 검사합니다. 실제 가속/최고속도/조향/브레이크/접지력/후진/관성 값은 `server.js`의 메인 물리 루프에서 사용합니다.

초급 버전은 화면의 기본 3개(최고 속도, 가속, 조향 민감도)만 조절하면 됩니다. 심화 설정은 `고급 튜닝` 버튼으로 4개를 더 열 수 있습니다.

## 맵 코드 위치
`tracks.json`에 10개 코스가 있습니다. 각 트랙은 닫힌 루프의 좌표 점(points) 목록입니다. 클라이언트와 서버가 같은 JSON을 사용하고, Catmull-Rom 방식으로 점 사이를 부드럽게 연결합니다. 서버는 자동차와 도로 중심선 사이의 거리를 이용해 랩 진행을 계산합니다.

## 부스트 규칙
- PC: F 키
- 모바일: BOOST 버튼
- 지속 시간: 3초
- 사용 후 재사용 대기: 10초
- 한 레이스에서 최대 5회
- 새 레이스가 시작되면 사용 횟수가 5회로 초기화됩니다.

`server.js`의 `canUseBoost()`가 횟수와 시간을 서버에서 검사하므로 화면 조작만으로 사용 횟수를 늘릴 수 없습니다.

## 경기
- 최대 8명
- 방장이 선택한 랩 수만큼 진행하며 전체 시간 제한은 없음
- 첫 완주자가 나오면 20초 추가 주행 후 결과 확정
- 방장만 맵 변경 및 시작 가능

## 변경 적용
기존 GitHub 저장소 대신 새 저장소를 사용 중이라면 이 ZIP을 풀고 파일을 모두 새 저장소의 루트에 올립니다. 이미 Render를 만들었다면 Render에 연결된 GitHub 저장소에 커밋하면 자동 배포됩니다(자동 배포가 켜져 있는 경우). 새 Render 서비스를 만들 필요는 없습니다.

[추가된 레이싱 HUD]
- 화면 아래쪽: 대형 속도계, 추정 RPM/기어, 스로틀/브레이크/조향 입력, 랩/순위/최고 랩/페널티
- 화면 오른쪽 위: 현재 트랙과 모든 참가자의 실시간 위치 미니맵
- 내 차량은 민트색, 다른 차량은 노란색 화살표로 표시
- 모바일 화면에서는 계기판과 미니맵이 작은 화면에 맞게 축소됩니다.
- RPM/기어는 현재 주행 속도를 기반으로 표시하는 게임용 추정값이며, 실제 엔진 센서 데이터는 아닙니다.


[레이스 진행 업데이트]
- 방장이 1~20랩을 선택할 수 있습니다.
- 레이스 시작 후 3초 카운트다운을 표시하고 동시에 출발합니다.
- 전체 제한 시간은 없습니다. 첫 완주자가 나오면 20초 추가 주행 후 경기가 종료됩니다.
- 주행 중 랩별 기록이 표시되고 결과 화면에도 각 랩 시간이 나옵니다.


[2026-11-26 계기판·미니맵·카운트다운·히트박스 보완]
- 계기판과 지도 갱신을 3D 렌더러 초기화와 분리해, Three.js CDN이 늦어도 온라인 HUD가 계속 갱신되도록 보완했습니다.
- 계기판은 서버 실시간 속도와 랩/순위/최고 랩/페널티, 내 조작 입력을 표시합니다. RPM/기어는 게임용 추정값입니다.
- 미니맵은 tracks.json 코스와 온라인 플레이어 좌표를 캔버스에 직접 그립니다.
- 카운트다운 표시는 새 레이스마다 3 → 2 → 1 → GO 순서로 시작하며, 반복 스냅샷 때문에 시간이 초기화되지 않습니다.
- 충돌 판정은 차량별 길이·너비·방향을 고려하는 회전 사각형(OBB)으로 변경했습니다. 작은 모서리 접촉은 무시하고, 접근 속도에 따른 약한 충격만 적용합니다.


[2026-11-26 트랙·계기판 보완]
- 10개 트랙 웨이포인트를 부드럽게 다듬고, 교차하던 트랙들을 다시 설계했습니다. 도로, 랩 판정, 미니맵은 같은 경로 샘플링을 사용합니다.
- 상단 중복 상태 UI를 숨기고 라이브 맵을 조금 키웠습니다.
- 전기차는 RPM을 표시하지 않고 모터 출력과 배터리를 표시합니다. 하이브리드는 EV와 엔진 모드를 자동 전환하며 EV 모드의 엔진 RPM은 0, 엔진 모드의 모터 출력은 0 W입니다.
- 하이브리드 배터리·전환 값은 게임용 표시 시뮬레이션입니다.


[2026-11-26 공통 튜닝·트랙 난도·슬립스트림 업데이트]
- 튜닝을 플레이어별 값에서 방 단위 공통 값으로 변경했습니다. 방장만 튜닝 슬라이더를 조절할 수 있으며, 서버가 모든 차량에 동일하게 적용합니다.
- 주요 트랙에 시케인 구간을 추가하고 10개 코스의 도로 폭을 약간 줄였습니다. 8대 출발 그리드가 도로 안에 들어오는지 검사했습니다.
- 앞차의 뒤쪽 5~19m 범위에서 같은 방향으로 달리면 슬립스트림이 발동합니다. 가속 +8%, 최고속도 +2.5%의 작은 보너스이며, 기존 부스트와 중복되지 않습니다.
- 잔디/흙 노면의 최고속도 제한과 감속을 완화했습니다. 잔디는 도로 대비 약 92%, 흙은 약 82%의 주행 성능을 유지합니다.


[관전 모드]
- 홈 화면의 관전 영역에 방 코드를 입력해 진행 중인 레이스에 입장할 수 있습니다.
- 관전자는 레이서 최대 8명 제한과 별도이며 방마다 최대 20명까지 가능합니다.
- 1위 자동 추적, 레이서 선택 추적, 전체 맵, 자유 카메라를 지원합니다.
- 자유 카메라: 화면 드래그 회전, W/A/S/D 또는 방향키 이동, Q/E 높이 조절, Shift 빠른 이동.
- 관전자는 차량 입력과 부스트를 사용할 수 없습니다.
- 홈 화면 온라인 인원은 레이서와 관전자를 모두 포함합니다.
