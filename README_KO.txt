# MISTWOOD ONLINE V2 — 튜닝·맵 선택 업데이트

## 포함 파일
- `index.html`: 게임 화면, 차량 선택, 튜닝 슬라이더, 10개 맵 선택, 부스트 HUD
- `server.js`: 온라인 방, 서버 권한 주행 물리, 랩 계산, 부스트 제한
- `vehicles.json`: 차량 외형/선택 데이터
- `tracks.json`: 10개 맵의 웨이포인트와 설명
- `package.json`: Node.js 실행 명령
- `render.yaml`: Render 배포 설정

## 실행
- Render Web Service의 Build Command: `npm install`
- Start Command: `npm start`
- Root Directory: 비워 둡니다.
- Runtime: Node

## 튜닝 코드 위치
`index.html`의 `TUNE_FIELDS`가 슬라이더 범위·간격·설명을 정합니다. `renderTuneFields()`가 UI를 만들고, 서버 `sanitizeTune()`이 범위를 한 번 더 검사합니다. 실제 가속/최고속도/조향/브레이크/접지력/후진/관성 값은 `server.js`의 메인 물리 루프에서 사용합니다.

초급 버전은 화면의 기본 3개(최고 속도, 가속, 조향 민감도)만 조절하면 됩니다. 심화 설정은 `고급 튜닝` 버튼으로 4개를 더 열 수 있습니다.

## 맵 코드 위치
`tracks.json`에 10개 코스가 있습니다. 각 트랙은 닫힌 루프의 좌표 점(points) 목록입니다. 클라이언트와 서버가 같은 JSON을 사용하고, Catmull-Rom 방식으로 점 사이를 부드럽게 연결합니다. 서버는 자동차와 도로 중심선 사이의 거리를 이용해 랩 진행을 계산합니다.

## 부스트 규칙
- PC: F 키
- 모바일: BOOST 버튼
- 지속 시간: 3초
- 사용 후 재사용 대기: 10초
- 한 레이스에서 최대 5회
- 새 레이스가 시작되면 사용 횟수가 5회로 초기화됩니다.

`server.js`의 `canUseBoost()`가 횟수와 시간을 서버에서 검사하므로 화면 조작만으로 사용 횟수를 늘릴 수 없습니다.

## 경기
- 최대 8명
- 방장이 선택한 랩 수만큼 진행하며 전체 시간 제한은 없음
- 첫 완주자가 나오면 20초 추가 주행 후 결과 확정
- 방장만 맵 변경 및 시작 가능

## 변경 적용
기존 GitHub 저장소 대신 새 저장소를 사용 중이라면 이 ZIP을 풀고 파일을 모두 새 저장소의 루트에 올립니다. 이미 Render를 만들었다면 Render에 연결된 GitHub 저장소에 커밋하면 자동 배포됩니다(자동 배포가 켜져 있는 경우). 새 Render 서비스를 만들 필요는 없습니다.

- 주행 중 랩별 기록이 표시되고 결과 화면에도 각 랩 시간이 나옵니다.


[2026-11-26 계기판·미니맵·카운트다운·히트박스 보완]
- 계기판과 지도 갱신을 3D 렌더러 초기화와 분리해, Three.js CDN이 늦어도 온라인 HUD가 계속 갱신되도록 보완했습니다.
- 계기판은 서버 실시간 속도와 랩/순위/최고 랩/페널티, 내 조작 입력을 표시합니다. RPM/기어는 게임용 추정값입니다.
- 미니맵은 tracks.json 코스와 온라인 플레이어 좌표를 캔버스에 직접 그립니다.
- 카운트다운 표시는 새 레이스마다 3 → 2 → 1 → GO 순서로 시작하며, 반복 스냅샷 때문에 시간이 초기화되지 않습니다.
- 충돌 판정은 차량별 길이·너비·방향을 고려하는 회전 사각형(OBB)으로 변경했습니다. 작은 모서리 접촉은 무시하고, 접근 속도에 따른 약한 충격만 적용합니다.
